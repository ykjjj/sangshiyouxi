# 体素丧尸生存游戏

一款基于 Three.js 的单文件体素世界丧尸生存 FPS 游戏。程序化生成的科幻风格武器、角色与场景，无需任何美术素材，`file://` 双击即玩。

![游戏类型](https://img.shields.io/badge/type-FPS-red) ![引擎](https://img.shields.io/badge/engine-Three.js_r0.149-green) ![许可](https://img.shields.io/badge/license-MIT-blue)

## 特性

- **体素世界**：128×48×128 程序化地形（草地/沙漠/石头/水域），方块可挖掘可建造
- **科幻风格建模**：能量青/等离子紫/纳米灰/全息透明四种核心材质，所有武器与角色程序化生成
- **17 种武器**：手枪、左轮、SMG、步枪、霰弹枪、狙击、LMG、火箭筒、剑、斧、球棒等，每把独立持握位姿与外观
- **多类型丧尸**：地面行走/飞行/BOSS（地面型 + 空中型），BOSS 顶部血条与远程弹幕攻击
- **波次玩法**：每波丧尸数量与难度递增，爆头 +30% 伤害，掉落重火力（火箭筒/高爆手雷）
- **塔防要素**：消耗能量币放置防空炮塔，自动锁定飞行丧尸，含视线遮挡检测
- **Minecraft 风格背包**：9 格快捷栏 + 27 格背包，E 键开关，拖拽交换
- **安全出生**：螺旋搜索 3×3 平坦区域，自动越阶 + 卡死自动跳跃脱困

## 快速开始

无需安装、无需服务器，**直接双击 `index.html` 即可在浏览器中运行**。

推荐使用 Chrome / Edge 等支持 WebGL 的现代浏览器。

## 操作说明

| 操作 | 按键 |
|---|---|
| 移动 | `W` `A` `S` `D` |
| 跳跃 | `空格` |
| 瞄准（ADS） | 鼠标右键 |
| 射击 / 挥砍 | 鼠标左键 |
| 换弹 | `R` |
| 切换武器 | 数字键 `1-9` 或滚轮 |
| 背包 | `E` |
| 放置方块 | 鼠标中键 / 对应快捷栏格 |
| 挖掘方块 | 长按左键对准方块 |
| 暂停 | `Esc` |

## 技术栈

- [Three.js r0.149](https://github.com/mrdoob/three.js) — WebGL 3D 引擎
- 程序化建模 — `mk()` 方块构造器 + 材质表 + 视图位姿表
- AABB 子步碰撞检测 + DDA 体素射线
- 单 HTML 文件，约 6000 行，零本地依赖
