## 二、4399 平台上架流程

1. 注册开发者：打开 4399 开发者中心（open.4399.net），注册账号并完成实名认证。
2. 创建游戏：选择「创建游戏」，类型选 **H5 游戏**，分类建议「射击」或「生存」，标签可加：丧尸、建造、塔防、多人。
3. 填写信息：
   - 游戏名称：建议「丧尸防线」（可自定义，需未被平台占用）
   - 游戏简介：第一人称丧尸生存+方块建造+塔防，波次防守、击杀 BOSS 解锁皮肤、支持局域网双人合作
4. 上传游戏包：直接上传 `release/4399提交包.zip`。要求 zip 根目录有入口 `index.html`（已满足）。
5. 上传素材：图标 + 3 张截图（materials 目录内）。
6. 提交审核：审核一般为数个工作日；若被驳回，常见原因是「游戏内按钮跳转外部链接」（本游戏联机面板显示的是局域网 IP 地址，属正常功能，iframe 内联机按钮已做自动隐藏处理，一般不会触发）。
7. 上架后：平台以 iframe 方式嵌入运行，联机按钮在 iframe 内自动隐藏，玩家看不到（局域网功能保留在自部署场景）。

## 三、PWA 安装说明

游戏已内置 PWA 支持（`manifest.webmanifest` + `sw.js` Service Worker + 192/512 图标）。PWA 要求 HTTPS 环境，本地 file:// 或纯 IP 地址无法安装。

### 部署到 GitHub Pages（免费 HTTPS 托管）

1. 将仓库推送到 GitHub（已推送 main 分支，含 index.html、manifest.webmanifest、sw.js、icons/、vendor/）。
2. 打开 GitHub 仓库 → **Settings** → **Pages**。
3. Source 选 **Deploy from a branch**，Branch 选 **main**，目录 **/ (root)**，保存。
4. 等待 1-2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可游玩。
5. 安装 PWA：
   - 安卓 Chrome：打开网址 → 菜单 →「添加到主屏幕/安装应用」
   - iOS Safari：分享 →「添加到主屏幕」
   - 桌面 Chrome/Edge：地址栏右侧安装图标 →「安装」
6. 安装后独立窗口运行、有图标、离线可玩（Service Worker 缓存了全部资源）。

### 其他托管（可选）

任何 HTTPS 静态托管均可：Vercel / Netlify（拖拽目录即部署）、或自有服务器 Nginx。要求 MIME：`.webmanifest` → `application/manifest+json`（`coop-server.py` 已配置，Nginx 需自行加 `types` 条目）。

## 四、版本更新

改动代码后重新打包：把最新的 `index.html` + `vendor/` 按上述 zip 结构压缩，重新上传平台；PWA 侧更新 `sw.js` 中的 CACHE 版本号即可强制刷新客户端缓存。
